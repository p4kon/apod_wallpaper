# NASA Science parser fixtures

Minimized, manually constructed fixtures based on responses inspected on
2026-09-28, not verbatim responses or a complete archive sample. The image case
adds distinct preview/original URLs and misleading metadata; the video includes
a poster deliberately. Text is shortened. Tests are offline and execute no HTML.
